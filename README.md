# Motion Minimalista com IA

Landing pública: https://motionia.pages.dev/

Este repositório contém somente a página comercial e os exemplos públicos autorizados. Skill, prompts, guias e videoaula são entregues privadamente pela Kiwify e não devem entrar no histórico Git nem em `site/`.

## Publicar

```sh
npx wrangler pages deploy site --project-name motionia --branch main
```

O projeto Cloudflare Pages foi criado com **deploy direto**. Um push no GitHub, por si só, não publica mudanças. Faça o deploy acima e confira a URL real depois.

## Configuração

`site/config.js` controla o link HTTPS do checkout. Sem link válido, a compra fica desativada. O suporte é conduzido pela Kiwify, conforme decisão do produtor; não há e-mail de suporte exposto na página.

Exemplos de vídeo: produção real aprovada pelo autor. As cenas que ilustram o Browser Use não são gravações de uso da ferramenta e estão identificadas como ilustração. O produto ensina edição, não Browser Use nem pesquisa automática.

Ferramentas e assinaturas de IA não estão incluídas no preço do material. Não há integração de pagamento própria, cookies de analytics ou pixels de anúncio adicionados por esta landing. O checkout é operado pela Kiwify.
